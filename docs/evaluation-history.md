## 值得保留的结论

### 摘要故障会表现为研究覆盖不足

当网页摘要的结构化输出请求不兼容时，日志出现大量失败并降级为截断原文。修复为 `function_calling` 后，多个依赖具体数字与完整枚举的案例回升。

这轮同时包含提示词调整，因此 0.736 → 0.912 的差额不能全部归因于提示词。以后研究分数下降时，应同时检查搜索、摘要、压缩与 judge 的实际运行状态。

### 信源回退缓解动态页面的数据缺口

当价格、限额等信息位于需要登录或前端渲染的页面时，静态抓取可能拿不到数据。2026-06-14 的单案实验中，转向可信第三方来源后，LLM API 对比案例的 coverage 从 0.429 上升到 0.714；同时加入时效标注的一次实验达到 1.000。

这是单次观察，受模型输出和 judge 波动影响，不能视为每次必得的增益。

### 时效标注实验存在代价

两个调整一起运行的全量实验，coverage 从 0.912 升到 0.955，grounding 从 1.000 降到 0.970。其中三条案例的 grounding 为 0.90，原诊断将其与无编号引用的时效说明关联；另外两条案例出现覆盖下降。

该实验不能证明所有回退只是随机波动，也不能把其成绩当成“仅采用信源回退”的独立验证。当前提示词已包含信源回退，但没有保留该实验要求的统一“截至检索日期”输出模板。
