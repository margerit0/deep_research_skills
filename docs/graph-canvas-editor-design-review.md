## 2. 本轮设计取舍

沿用当前工作台的银白／石墨颜色、圆角卡片、细线图标和蓝色选中态。编辑视图将工作台导航收为窄栏，为节点库、画布、参数面板保留空间。

| 区域 | 可评审的内容 |
| --- | --- |
| 工作台与流程管理 | 从工作台进入流程管理，从已有草稿继续编辑，或从标准模板创建未发布草稿 |
| 主画布 | 节点拖动、平移、缩放、适应画布、自动布局、撤销／重做 |
| 节点库 | 澄清可移除及重新添加；两个扩展类型可插入；必需节点带锁定提示 |
| 参数面板 | 名称与处理要求、模型角色、输入输出和允许插入的位置；角色沿用研究配置 |
| 连接 | 端口操作以及可用键盘访问的连接表单；阶段不相容或成环时拒绝连接 |
| 校验 | 问题计数、定位节点／字段、补齐参数和断连后重新校验 |
| 保存异常 | 失败后重试；冲突时另存副本，或保留备份再载入较新草稿；备份可恢复为独立草稿 |
| 发布 | 保存与校验后确认发布；版本转为只读；编辑副本不改写发布快照 |
| 新研究与运行 | 从发布版本进入新研究，填写问题后才进入运行示例；研究员在运行详情中查看 |

开始、初始化、研究简报、研究协调子流程、最终报告、结束均保留。删除可选节点时说明关联连线的变化，并在端口相容时提供“同时连接前后节点”选项。删除可撤销。

首版主流程的正常连接保持阶段顺序。澄清的等待回答出口以系统路径显示；原型不将该路径、研究员实例或协调器内部循环变为可编辑节点。

窄屏采用“画布／节点库／属性”切换，节点改为纵向排列。点击节点可检查参数；当前稿未提供完整触屏拖拽编排承诺。

本稿聚焦交接要求的关键页面与状态。批量框选、完整版本历史、多流程持久管理、归档、导入导出和真实模型／Skills 选择仍属于后续正式设计及实现，不应据此原型宣称完成。

## 3. 实际验证

验证环境：现有 Chrome 和项目现有 Playwright，打开独立预览文件。没有启动或修改生产前后端。

- 14 个浏览器交互场景通过：核心锁定与参数保存；可选节点增删及撤销／重做；澄清移除与恢复；拖动及整步撤销；删除和重连及非法连接拦截；校验定位与修复；发布到新研究及研究员查看；冲突另存；冲突备份恢复；保存失败及重试；发布快照不变；模板创建并首次发布为 v1.0；窄屏面板与弹窗；键盘输入及对话框焦点。
- 1440 浅色、1024 浅色、1024 深色、390 浅色、320 浅色共 5 个布局组合完成检查；可见控件均位于界面横向边界内，未发现横向溢出。
- 桌面浅色／深色、发布、冲突、运行观察及窄屏属性面板截图已人工查看。
- 最终浏览器结果：未发现 JavaScript 页面错误，未发出研究后端请求。
