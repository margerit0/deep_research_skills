# 流程编辑与版本管理

M2–M3 已将确认的设计和真实执行接入正式工作台。后端存储就绪并在 `/atlas/config` 声明 `workflow_editor_version: 1` 后，侧栏显示“流程管理”；也可打开 `/#workflows`。更新代码后重启后端与前端。编辑页面按需加载，原研究会话和演示记录继续可用。

生产服务支持草稿管理、不可变发布和流程执行。编译器、节点实现或运行时不可用时明确拒绝发布／执行，可以继续查看已有完整版本，不会替换成内置图。执行入口仅在后端声明 `workflow_execution_version: 1` 时开放。

## 编辑草稿

1. 在流程管理中选择“新建流程”或“使用标准模板”，填写名称后创建草稿。
2. 从左侧节点库点击或拖入“研究计划优化”“材料整理”，相容的前后节点会自动连接。两类节点可重复添加，参数分别保存。
3. 选择画布节点，在右侧修改名称和处理要求。处理要求最多 4000 个 Unicode 字符；必需步骤不可删除，澄清可以移除并重新添加。
4. 拖动节点调整布局。拖动端口或使用右侧“连接节点”表单连线；删除已有连线后可重新选择后继。错误阶段、已有入口／出口和循环连接会被拒绝。
5. 修改后约 800 毫秒自动保存，也可点击“保存”或按 Ctrl／⌘ S。一次拖动或节点操作对应一个撤销步骤；缩放和平移保存视口，不占用节点操作的撤销记录。

主流程最多 30 个节点，包含开始、初始化和结束。澄清等待回答是系统路径，研究员任务属于运行实例；它们不会成为可删除的主流程步骤。

Ctrl／⌘ Z 撤销，Ctrl／⌘ Shift Z 或 Ctrl Y 重做。选择节点或连线后可按 Delete；输入框与中文输入法不会触发画布删除或撤销。画布节点支持键盘选中及方向键移动；对话框支持 Tab 和 Escape。

窄屏提供“画布／节点库／属性”查看切换；编辑需要桌面宽度。银白、石墨及系统主题均可使用，并遵循减少动画设置。

## 保存失败与冲突

“已保存”表示当前文档和布局已被服务端确认。保存中的较旧响应不会覆盖继续输入的内容；连续写入按顺序合并。响应丢失时先回读完整文档，不能只比较执行摘要。

服务器已有更新或回读内容不同时，保留本地修改并暂停覆盖写入。可以“另存本地副本”，或先下载 JSON 备份再载入服务器版本。离开未保存页面时也提供备份操作。

浏览器保存每个窗口的恢复副本，并保存创建／发布请求标识。复制浏览器标签页后，各窗口仍优先读取自己的副本；原请求重试不分配新标识。本地存储不可用时会显示提示，创建和发布不会在请求标识未保存的情况下发出。重要的未确认内容可使用“导出流程 JSON”另存文件。

暂时清空名称或标签不会丢弃其他本地编辑；填回合法名称后才能保存。恢复本地内容仍需要连接服务端，以核对当前草稿版本。

## 校验、发布和历史

本地结构检查用于定位问题；服务端发布校验还会检查确切保存版本、可用节点实现、编译器以及模型／Skills 引用。点击问题可定位节点或参数。断连、未知类型和未填处理要求可以存在于结构合法的草稿中，但不能通过发布校验。

发布前先保存并校验，再确认版本说明。成功发布生成 v1、v2 等不可变版本，保留完整名称、参数、布局与视口；原流程草稿的基础修订和编辑版本同时更新。发布结果未确认时使用“重试发布”，沿用原请求标识。

“编辑当前草稿”继续同一流程已有的草稿，不会用一个旧版本覆盖较新内容。“复制为新流程”将旧版本复制到新的流程身份；原发布版本和原草稿保持各自的内容。

导入仅接受 v1 `WorkflowDocument` JSON，不接受发布身份、thread 绑定、运行事件、凭据或节点级模型覆盖。导出只包含流程名称、定义和展示信息。归档保留草稿、发布版本及已有研究引用；归档流程可查看与复制，不能继续编辑或发布。

## 使用发布版本研究

在已发布版本页点击“使用此版本发起研究”，工作台创建新的会话并显示流程名称、版本。填写问题并发送后才创建原生执行；模型与 Skills 可在发送前选择，没有显式覆盖时采用流程默认配置。

一个会话固定使用一个版本。补充澄清、后续研究、重试和恢复沿用原版本；切换版本须从对应发布页创建新会话。发布新版本不改变旧会话。归档禁止新的会话选择，已有受支持绑定仍可继续；旧内置图会话不能在原 thread 内升级。

运行图按发布顺序展示步骤和扩展节点，提供只读节点详情。状态来自核对归属后的事件及检查点；研究员来自实际委派，显示在协调器下方。刷新、重连、查看发布版本和历史回放均不启动研究。

执行中断后，只有澄清、简报和报告三个安全边界可能出现恢复操作；计划优化、材料整理及研究子流程内部中断保留成果并提供新研究入口。原实现不可用时只能查看已有完整归档，不能换用最新版本续跑。

开发与验收入口见 [M3 验证记录](../../docs/graph-canvas-editor-m3-results.md)；精确接口和迁移约束见 [v1 契约](../../docs/graph-canvas-editor-contract.md)。真实模型质量和性能验收仍属于 M4。
