## 播放与覆盖范围

进入 **全流程演示**，在 **数据来源** 选择实录。支持播放、暂停、章节跳转、倍速、重播和节点检查。回放不新建后端执行，不修改会话、草稿或模型配置；退出和刷新恢复原工作区。此前已启动的在线研究可以继续回读。

Kimi 的两个研究任务一失败、一完成。检索工具共开始 5 次，4 次结束、1 次失败；工具内部可能包含重试，这些事件数不是原始搜索 HTTP 次数。模型 HTTP 尝试包括 19 次 200、1 次 504、39 次连接失败和 1 次响应未记录，单步探针另计。

图谱与检查器显示实录配置、节点、笔记和事件；未开始的阶段保持未执行，写作中断保留最后的检查点状态。实录没有收到报告正文，不能用模拟报告补齐，也不能把离线章节播放算作计划 3 的在线报告流式验收。

## 数据出处

- [GLM 退避实测证据](provider-2026-10-13-backoff-evidence.json) 和 [Kimi 实测证据](provider-2026-10-13-kimi-evidence.json) 保存配置、身份、逐次请求、退避与限制。
- [recordings.json](../src/data/recordings.json) 是界面的安全数据集；[recordings.ts](../src/data/recordings.ts) 延迟加载并校验研究结构，生成章节与节点。
- 每条实录各有一个 thread、两次用户提交和两个 run，彼此独立。最终数据按所属 API 状态、受理配置和事件核对，不拼接不同实测轮次。
- Kimi 的后续浏览器快照仍停在 `research`，来源为 0；最终简报、笔记、30 条事件及 8 条来源取自另存的直接 API 快照，`running/writing` 与来源数由退出后的磁盘检查点再次确认。浏览器来源一致性和最终业务检查点验收没有通过。
- 目前公开数据不含模型推理、原始搜索全文、密钥、网关明文或可执行的数据库备份。模型输出、笔记和工具 URL 是实测材料，仍需结合业务状态与后续报告引用核验阅读。

## 本地下载包

本轮下载包保存于项目根目录的 `.local/exports/atlas-real-calls-2026-10-13.zip`，整理日期为 2026-10-14。`.local/` 不进入 Git；仓库保留安全的 JSON 实录与公开证据。包内共有 56 个文件：

- `SUMMARY.json`：四轮独立测试的业务状态、run 数量和成果覆盖。
- `rounds/*/`：三轮 GLM 与一轮 Kimi 的证据、对话、最后状态、固定检查点、回执、笔记、来源、研究事件、HTTP 尝试、退避和已保留截图。
- `recordings.json`：与前端数据一致的两条只读实录。
- `MATERIALS-AUDIT.json`：原始材料的当前可用性及校验结果。
- `manifest-sha256.json`：包内文件的 SHA-256，另由 ZIP CRC 检查压缩包完整性。

原路径仍可读取的 26 份材料均匹配历史 SHA-256。4 个临时路径已被上一轮 Playwright 清理：180 秒轮 trace、600 秒轮观察 JSON、退避轮观察 JSON 及截图；退避轮截图在此前导出目录有匹配的副本，其余缺失原件没有重建。Kimi 的 7 份已列入证据索引的本地材料全部可校验。Kimi 原始实时截图没有成功保存；下列图片来自离线回放界面。
