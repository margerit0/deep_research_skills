## 唯一质量变量

候选稿核验的 system prompt 增加通用的决定复核要求：比较断言的完整含义；从原始要求和实际原文检查遗漏，不把来源条件选择当成完整清单；拒绝前核对全文是否已保留限定；只保留有实际来源依据、影响事实或建议的问题。没有增加 Python 场景答案清单。

写作提示、来源条件选择、输出 schema、模型与参数保持一致。两种提示均使用 `deepseek-v4.1-flash`、enabled/high、128000 token 上限、温度 0、实际 usage 尾块。SDK 每次读取最多五次 HTTP 尝试，原有流传输重读规则和 3／6／12／24 秒 SDK 退避不变。TLS 校验保持开启，模型客户端显式 `proxy=None`、`trust_env=False`，沿用原网关与凭据。
