This media scene imports the original frontend components and pinned frontend dependencies.
No additional npm packages are installed. Run `serve.mjs` from this repository, then
`render-preview.mjs`. Chrome or Edge, FFmpeg/ffprobe, Python 3 and Pillow are required.
The browser is isolated, uses no personal profile, blocks external network and `/api/` calls.
Do not copy this folder alone as an independent source package: it requires the repository
files listed with SHA-256 in `brief.json`. Original project and dependency licenses apply.
