# 星图工作台 · 产品演示 v2

本版根据“先添加浏览器全屏的完整 UI 预览，然后再聚焦于输入框”修订开场。

- 0–1 秒：完整浏览器画面，显示原生侧栏、对话区、输入框和待执行图谱。
- 1–2 秒：同一个界面连续聚焦输入框。
- 2–3 秒：原文问题稳定停留；第 60–74 帧淡入旁侧说明文案。
- 3–12 秒：并行研究、节点检查器、报告和品牌收尾。报告稳定阅读 2.5 秒，品牌静止 1 秒。

`preview/index.html` 是预览入口，`preview/motion-sample.mp4` 是前 8 秒无声小样。默认五个时间点全部保留，另补充完整工作台、输入框落位、图谱落位三帧；总览显示六个主要画面。

本版等待预览确认，`final/` 尚无新成片或配乐。上一版已确认视频保留在 `../2026-10-25-v1/final/`。本版没有沿用上一版的批准状态。

源码与原生组件依赖记录在 `brief.json`，统一帧时间轴为 `timeline.json`；复现方法及验证结果见 `preview/reproduce.md` 和 `preview/verification.md`。
