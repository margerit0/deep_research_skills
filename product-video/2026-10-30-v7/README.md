# v7 · 配乐重写与转场修订

复查 README 现用的 v6 成片后，镜头结构和文案没有发现需要改动的问题，主要问题在配乐，其次是几处转场。用户已在请求中预先授权本次无需确认分镜，因此直接完成了完整视频。镜头顺序、时长和除版本标记外的屏幕文案都与 v6 相同。

## 复查结论与修改

| 位置 | v6 的问题 | v7 的处理 |
|---|---|---|
| 配乐结构 | 配器全片不变，响度范围仅 1.2 LU；和声与旋律循环错位，旋律每拍不停 | 九段结构随镜头展开，旋律有乐句和停顿，响度范围 5.9 LU |
| 配乐音色 | 综合响度 -19.1 LUFS，6 kHz 以上约 -56 dB，声音偏闷 | 综合响度 -16.1 LUFS，高频补足，低音加入谐波以照顾小扬声器 |
| 动作音效 | 讲解动作共用同一个短音，章节卡没有音乐标记 | 音效按事件区分并跟随当前和弦；章节卡有独立的低频与钟声 |
| 结尾 | 律动持续到淡出 | 50 秒落在主和弦，钟声延音，最后一秒自然收束 |
| 16、19 秒章节卡 | 标题与密集报告文字重影约 0.4 秒，页脚两段说明叠加 | 底色先盖住报告再显示标题，退出时相反；页脚说明在遮盖完成后切换 |
| 19 秒报告缩入 | 报告窗口压住看板顶栏文字 | 顶栏等窗口离开后再淡入，左栏标题与章节标签同步替换 |
| 8、13 秒镜头 | 平移扫过大片空白 | 改为中途拉远再推进的弧线运动 |
| 23–44 秒镜头切换 | 标题与图解标题硬切 | 0.2 秒淡入 |
| 50 秒品牌收尾 | 叠化在图解上 | 与章节卡相同的两段式转场 |
| 全片文字 | 动画前后抗锯齿跳变 | 灰阶字形渲染 |

## 配乐结构

D 大调，120 BPM，所有声音由代码合成。段落、和声与音效位置都从 `plan.json` 派生。

| 时间 | 画面 | 音乐 |
|---|---|---|
| 0–4 秒 | 完整工作台、提出问题 | 和声垫、长低音与轻打击，开场动机首次出现 |
| 4–8 秒 | 选择 Skill | 动机的回应句，两次原生点击留出空间 |
| 8–16 秒 | 并行研究、查看过程、报告 | 完整律动，三声部琶音在左中右走位，对应三个并行方向 |
| 16–19 秒 | 章节卡 | 鼓点退出，低频与钟声标记章节，末尾上升音效接入第二部分 |
| 19–27 秒 | 方法与评估 | 全片最安静，轻打击加拨弦提示，让位给阅读 |
| 27–37 秒 | 诊断与候选 | 柔和琶音进入，和声转向关系小调 |
| 37–44 秒 | 独立验证 | 低音加密、打击逐层增加，末尾上升音效 |
| 44–50 秒 | 人工采纳 | 全片最响，完整律动与开场动机的明亮再现 |
| 50–53 秒 | 品牌收尾 | 主和弦与钟声琶音延音，最后 1 秒自然收束 |

## 听感验收

数值检查不能代替听感，工具环境本身不做主观听音。用户于 2026-10-30 试听当前成片后确认满意，原话与成片哈希记录在 [授权记录](approval.json) 的 `acceptance`。交付时建议的试听重点如下，后续修订配乐时可以沿用：

- 8 秒：律动和琶音进入后，是否抢过画面。
- 16 秒：章节卡的低频与钟声是否醒目但不过重。
- 19–37 秒：配乐是否足够退后，不干扰阅读。
- 44 秒：动机再现是否有释放感；这一段比全片响约 3 LU，是否偏响。
- 50–53 秒：收尾和弦是否自然结束。
